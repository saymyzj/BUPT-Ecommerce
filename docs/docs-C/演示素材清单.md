## 录制流程

视频按 `docs/docs-C/演示视频脚本.md` 的主线录制：

1. 展示 Gateway 统一入口和服务状态。
2. 管理员登录。
3. 创建商品、设置库存、创建秒杀活动。
4. 普通用户注册登录并建立 SSE 推送连接。
5. 发起秒杀，展示 `QUEUEING`。
6. 等待并展示 `ORDER_CREATED` 推送。
7. 使用 `orderId` 查询订单详情。
8. 调用 AI 商品咨询。
9. 展示 Apifox 8 个分组、“08 完整演示流程”的 12 步测试、环境变量。
10. 简述生产演进：Gateway 多实例、Redis Sentinel / Cluster、RabbitMQ 集群、MySQL 主从、AI 缓存/限流/排队/降级。

## 敏感信息处理

用户补充的 Apifox 原始截图用于剪入演示段；最终生成的 `07-apifox-groups.png`、`08-apifox-env.png` 已对 token、密码等敏感值做遮罩。原始 Apifox 截图仍可能包含 token 或密码，不建议直接提交到远程仓库。
