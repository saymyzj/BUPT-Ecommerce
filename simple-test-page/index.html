B+

可选增强

异常恢复
B+ 是什么 这是管理员/运维视角的兜底能力，不是普通用户购物流程。用于展示 Redis 数据丢失、MQ 投递不确定、坏消息进入队列时，系统如何恢复。
Redis 重建库存：按 MySQL 订单和资格记录反推 Redis 库存，证明不会凭空加库存。
投递事件/重试投递：查看秒杀资格到 RabbitMQ 的可靠投递状态，异常时可幂等重试。
死信列表/重放死信：坏消息不会堵住正常队列，会进入死信记录等待排查和重放。
异常恢复观察

这里展示 B 成员新增的 Redis 库存重建、可靠投递事件和死信恢复接口。

死信记录

先按文档向 RabbitMQ 投递一条非法消息，再点击“死信列表”即可看到记录。
