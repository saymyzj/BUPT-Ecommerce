# 第1周任务报告

> 角色：成员 A  
> 周期：第 1 周  
> 主题：完成 Gateway 与用户认证基线，建立统一入口、统一鉴权和统一契约入口

## 1. 本周目标

本周围绕成员 A 的核心职责，完成以下基础能力：

1. Gateway 统一入口与路由转发。
2. JWT 鉴权与角色拦截。
3. 用户注册、登录、管理员登录、当前用户信息、注销接口。
4. 接口契约巡检与基础 Swagger/OpenAPI 汇总入口。

## 2. 已完成工作

### 2.1 Gateway 基线

1. 配置了 Gateway 统一入口，端口为 `8080`。
2. 保持已有路由转发结构：
   - `/api/auth/**`、`/api/users/**` -> `user-service`
   - `/api/products/**`、`/api/seckill/**` -> `product-seckill-service`
   - `/api/orders/**` -> `order-service`
   - `/api/ai/**` -> `ai-service`
   - `/api/push/**` -> `push-service`
3. 新增 JWT 鉴权过滤器：
   - PUBLIC 接口放行。
   - CUSTOMER / ADMIN 接口强制鉴权。
   - ADMIN 接口做角色拦截。
4. 失败响应统一返回：
   - `401` 未登录或 Token 无效
   - `403` 无权限
5. 通过 Gateway 向下游注入用户上下文头：
   - `X-User-Id`
   - `X-Username`
   - `X-User-Role`

### 2.2 用户服务基线

1. 完成 `POST /api/auth/register`
2. 完成 `POST /api/auth/login`
3. 完成 `POST /api/auth/admin/login`
4. 完成 `GET /api/users/me`
5. 完成 `POST /api/auth/logout`
6. 登录接口返回真 JWT，payload 口径包含：
   - `userId`
   - `username`
   - `role`
   - `iat`
   - `exp`

### 2.3 统一契约与公共组件

1. `common` 模块补充了 JWT 工具与认证头常量。
2. 统一响应格式保持为：
   - `code`
   - `message`
   - `data`
3. 统一错误码保持与规范一致。

### 2.4 接口契约巡检

1. 核查了所有已存在控制器的 `/api` 前缀。
2. 核查了统一 Gateway 对外入口。
3. 核查了统一响应格式。
4. 核查了分页字段为 `page/pageSize/records/total`。
5. 核查了枚举命名为大写英文。
6. 修正了 AI 咨询与推送 SSE 中的契约偏差。

### 2.5 Swagger/OpenAPI 起步

1. 为 Gateway 补了 OpenAPI 聚合入口路由。
2. 为核心服务补了 springdoc 依赖。
3. 为核心控制器补了 `@Tag`、`@Operation` 注解。
