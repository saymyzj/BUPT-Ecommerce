## 4. 接口遵循情况

测试页按 `docs/API接口契约.md` 使用以下接口：

| 能力 | 接口 | 权限 |
| --- | --- | --- |
| 用户注册 | `POST /api/auth/register` | `PUBLIC` |
| 用户登录 | `POST /api/auth/login` | `PUBLIC` |
| 管理员登录 | `POST /api/auth/admin/login` | `PUBLIC` |
| 当前用户 | `GET /api/users/me` | `CUSTOMER` / `ADMIN` |
| 创建商品 | `POST /api/products` | `ADMIN` |
| 设置库存 | `PUT /api/products/{productId}/stock` | `ADMIN` |
| 创建秒杀活动 | `POST /api/seckill/activities` | `ADMIN` |
| 发起秒杀 | `POST /api/seckill/activities/{activityId}/orders` | `CUSTOMER` |
| 订单列表 | `GET /api/orders` | `CUSTOMER` |
| 订单详情 | `GET /api/orders/{orderId}` | `CUSTOMER` / `ADMIN` |
| AI 咨询 | `POST /api/ai/products/{productId}/consult` | `CUSTOMER` |
| 推送订阅 | `GET /api/push/orders/subscribe` | `CUSTOMER` |
