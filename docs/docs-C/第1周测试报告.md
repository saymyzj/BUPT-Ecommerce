# 成员 C 第 1 周测试报告

## 1. 测试目标

验证成员 C 第 1 周交付的测试页基础能力是否符合 `docs/API接口契约.md`、`docs/统一响应格式与错误码.md`、`docs/认证与权限规范.md` 和 `docs/Apifox接口清单.md`。

重点检查：

1. 所有请求是否通过 Gateway。
2. 登录后是否正确保存 token 和角色信息。
3. 管理员接口和普通用户接口是否按权限分离。
4. 测试页是否只展示真实接口返回，不伪造秒杀或订单成功。
5. SSE 推送入口和 AI 咨询入口是否具备联调条件。

## 3. 测试用例

| 编号 | 测试项 | 操作 | 预期结果 | 实际结果 |
| --- | --- | --- | --- | --- |

| C-W1-05 | 当前用户查询 | 携带 token 调用 `GET /api/users/me` | 返回当前登录用户信息 | 通过 |
| C-W1-06 | 创建商品 | 携带 adminToken 调用 `POST /api/products` | 返回 `productId` | 通过 |
| C-W1-07 | 设置库存 | 调用 `PUT /api/products/{productId}/stock` | 库存设置成功 | 通过 |
