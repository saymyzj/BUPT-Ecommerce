## 5. 演示流程

最终演示视频按以下主线录制：

1. 展示 Gateway 统一入口和服务状态。
2. 管理员登录。
3. 创建商品、设置库存、创建秒杀活动。
4. 普通用户注册登录并建立 SSE 推送连接。
5. 发起秒杀，展示 `QUEUEING`。
6. 收到 `ORDER_CREATED` 推送。
7. 使用 `orderId` 查询订单详情。
8. 调用 AI 商品咨询。
9. 展示 Apifox 8 个分组、环境变量、12 步完整流程。
10. 简述生产演进：Gateway 多实例、Redis Sentinel / Cluster、RabbitMQ 集群、MySQL 主从、AI 缓存/限流/排队/降级。
